# Junior Machine Learning Engineer

**Blue Heron Robotics** - Pittsburgh, PA (on site)

We build inspection robots for warehouses and cold-storage facilities. The perception
team is hiring a junior engineer to help turn experiments into reliable production features.

## The work

- Clean and label sensor data, and build the data pipelines that feed model training.
- Train and evaluate classical models and small neural networks; report results honestly.
- Prototype operator-facing features that call large language model APIs to summarize
  inspection runs.
- Write tests and documentation for everything you ship.

## You might be a fit if you have

- A bachelor's degree in computer science, statistics or a related field.
- Solid Python, including Pandas and Scikit-learn.
- A project where you compared models and explained why one was better.

## Bonus

- Experience with time-series or location data.
- Curiosity about robotics hardware.

Salary range: $78,000 - $92,000. Relocation assistance is available.
