# Web Developer

**Pinecrest Media** - Columbus, OH (on site)

Pinecrest Media publishes regional lifestyle magazines and their websites. We need a web
developer to build page templates and keep our publishing sites fast and accessible.

## Responsibilities

- Build and maintain page templates and components for our content management system.
- Implement designs in JavaScript, TypeScript and React with attention to accessibility.
- Monitor page performance and fix regressions.
- Support editors with publishing questions during weekday business hours.

## Requirements

- A portfolio of web projects.
- Solid HTML, CSS and JavaScript; React experience preferred.

Salary range: $58,000 - $66,000.
