# Junior Security Analyst

**Ironleaf Insurance Group** - Columbus, OH (on site)

Ironleaf's security operations team protects policyholder data across our offices and cloud
services. This entry-level analyst role is a path into security engineering.

## Duties

- Monitor alerts from endpoint and network tools and escalate real incidents.
- Review access requests and help enforce least-privilege policies.
- Harden Linux and Windows hosts against our baseline and track exceptions.
- Contribute to awareness training based on the OWASP Top 10 and recent phishing trends.

## Requirements

- Associate or bachelor's degree, or a completed technical bootcamp.
- Familiarity with networking fundamentals: subnets, ports, DNS and common protocols.
- Basic scripting in Bash or Python.
- Willingness to work one weekend shift per month.

## Preferred

- A security-focused certification, or one in progress.

Salary range: $65,000 - $75,000.
