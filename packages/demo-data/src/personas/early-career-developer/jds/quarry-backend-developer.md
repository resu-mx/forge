# Backend Developer I

**Quarry Labs** - Remote (US)

Quarry Labs makes a hosted test-data service for development teams. We are a small company,
and every engineer works across the stack, but this role is mostly backend.

## What you will work on

- Python services that generate and serve synthetic datasets over a REST API.
- PostgreSQL schemas, migrations and query tuning.
- Docker-based local environments and the CI that runs our test suite.
- Customer-reported bugs: reproducing them, fixing them and writing the regression test.

## About you

- Up to two years of professional experience, internships included.
- Comfortable reading unfamiliar code and asking good questions.
- Able to work independently across time zones with written communication.

Salary range: $75,000 - $90,000, fully remote within the US.
