# Data Engineer I

**Kestrel Analytics** - Cincinnati, OH (hybrid)

Our data engineering team ingests point-of-sale exports from hundreds of retail customers and
turns them into the clean tables our forecasting models depend on.

## What you will do

- Write and maintain ingestion jobs in Python, using Pandas for transformation steps.
- Model warehouse tables in PostgreSQL and write the SQL that analysts build on.
- Add data quality checks and alerts so bad files are caught early.
- Document datasets so other teams can use them without asking.

## What you bring

- Strong SQL, and Python you are happy for others to read.
- A project that involved cleaning a messy real-world dataset.
- Interest in how data quality affects downstream models.

Salary range: $74,000 - $88,000.
