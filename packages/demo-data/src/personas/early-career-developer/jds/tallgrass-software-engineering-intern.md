# Software Engineering Intern (Summer)

**Tallgrass Software** - Remote (US)

Tallgrass makes scheduling software for independent veterinary clinics. Our twelve-week summer
internship pairs each intern with a mentor and a real feature to ship.

## During the internship you will

- Pick up a backlog feature and take it from design notes to production.
- Write Python or Java code, with tests, and get it reviewed by the team.
- Present your work at the end-of-summer demo day.

## We are looking for students who

- Are working toward a degree in computer science or a related field.
- Have completed a data structures course.
- Use Git comfortably and can explain a project they built.

Compensation: $28 per hour. Applications for this cohort are now closed.
