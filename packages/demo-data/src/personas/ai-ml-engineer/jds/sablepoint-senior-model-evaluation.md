# Senior Engineer, Model Evaluation

**Sablepoint AI** - San Francisco, CA (hybrid)

Our agents make decisions on behalf of customers, so we need to know, with numbers, when a new
model or prompt makes them better or worse. The evaluation team builds the datasets, harnesses
and dashboards that answer that question for every release.

## Responsibilities

- Build and maintain offline evaluation suites for multi-step agent tasks.
- Design labeling guidelines and work with domain experts to grow golden datasets.
- Run controlled experiments comparing models, prompts and tool configurations.
- Turn evaluation results into release decisions that product and research both trust.

## Requirements

- Five or more years in ML engineering or applied science.
- Fluency in Python and the scientific stack; comfortable writing production code.
- Experience designing experiments and reasoning about statistical significance.
- Hands-on work evaluating large language models.

## Bonus

- Experience with deterministic replay or trace-based testing.

Base salary range: $205,000 - $250,000, plus equity.
