# Staff Engineer, Agent Platform

**Sablepoint AI** - San Francisco, CA (hybrid, two days a week in the office)

Sablepoint builds autonomous agents that handle back-office work for mid-sized insurers and
lenders. Every agent run touches customer systems, so the platform underneath has to be fast,
observable and safe by default. We are a team of about ninety, and the platform group is twelve.

## What you will do

- Own the architecture of the agent runtime: planning loop, tool execution, retries and state.
- Design sandboxing and permission boundaries for tools that call customer APIs.
- Build evaluation and replay infrastructure so every model or prompt change is measured
  before it ships.
- Set technical direction across three teams and mentor senior engineers.
- Work directly with customers' security reviewers on how agents are contained.

## What we are looking for

- Eight or more years building production systems, including two or more on LLM-backed
  products or agent infrastructure.
- Strong Python; Rust or another systems language is a plus.
- Experience running workloads on Kubernetes at meaningful scale.
- A clear point of view on prompt injection and how to contain it.

## Nice to have

- Open-source work in the agent or evaluation space.
- Talks or writing that explain hard technical ideas simply.

Compensation: $245,000 - $300,000 base, plus equity and benefits.
