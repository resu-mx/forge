# Staff Platform Security Engineer (internal posting)

**Ridgeback Federal Solutions** - Chantilly, VA (hybrid)

Ridgeback's corporate platform security team builds the shared tooling that every program
uses to harden, deploy and monitor its systems. This posting is open to current employees.

## Responsibilities

- Maintain the company's hardening baselines as code and the pipelines that enforce them.
- Provide secure Kubernetes and Terraform modules to program teams.
- Consult with programs on platform architecture and authorization impacts.
- Represent platform security in the engineering guild.

## Requirements

- Current Ridgeback employee in good standing with an active Secret clearance or higher.
- Six or more years of infrastructure or security engineering experience.
- Strong Linux, Ansible and Terraform skills; Kubernetes experience preferred.

Salary range: $182,000 - $206,000. Internal applicants should notify their program manager
before applying.
