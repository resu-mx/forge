# Senior DevSecOps Engineer

**Halyard Analytics Group** - Remote (US)

Halyard builds analytics software for defense planners and ships it into accredited
environments. Our DevSecOps engineers make secure delivery the default path for every team.

## Responsibilities

- Build and maintain CI/CD pipelines that sign, scan and promote container images.
- Write Terraform and Kubernetes manifests for development and production enclaves.
- Integrate policy checks into pull requests so findings are caught before release.
- Write tooling in Go to automate evidence for security assessments.

## Requirements

- Five or more years in DevOps, platform or security engineering.
- Strong Docker, Kubernetes and Terraform experience.
- Ability to obtain a Secret clearance.

## Nice to have

- Experience shipping software into classified or air-gapped environments.

Salary range: $166,000 - $190,000, remote within the US.
